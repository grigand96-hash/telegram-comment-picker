# Рандомайзер для конкурсов в Telegram

Сервис ZNWR для случайного выбора комментария под конкурсным постом в Telegram. Вставьте ссылку на пост, нажмите «Выбрать комментарий» и откройте ссылку на результат. Можно выбирать повторно.

[Открыть рандомайзер на GitHub Pages](https://grigand96-hash.github.io/telegram-comment-picker/)

Страница на GitHub Pages подключается к сервису на вашем компьютере. Запустите его по инструкции ниже и разрешите доступ к локальной сети, если браузер спросит. Для входа в Telegram откройте локальную страницу. Публичный сайт получает состояние подключения и выбранный комментарий.

Каждое доступное сообщение в обсуждении имеет один шанс, включая сообщения с фото и ответы другим участникам. Один автор может участвовать несколькими комментариями. Проверку условий конкурса выполняет организатор.

## Запуск

Требуется Python 3.10 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:8894. При первом запуске укажите собственные Telegram API ID, API hash и номер телефона, затем введите код и облачный пароль, если он запрошен.

Сервис слушает только локальный адрес компьютера. API hash и авторизованная Telegram-сессия хранятся вне репозитория в `~/Codex/context/projects/znwr/telegram-picker-private`. Каталог можно переопределить через `ZNWR_PICKER_DATA_DIR`. Файлы создаются с закрытыми правами. Код входа и облачный пароль используются для авторизации и не записываются приложением на диск.

## Как выбирается комментарий

1. Сервис получает всю доступную аккаунту ветку обсуждения через Telegram API.
2. После успешной полной загрузки сохраняет сообщения в памяти процесса.
3. `secrets.choice` выбирает равновероятно одно сообщение.
4. Сервис возвращает автора, текст или тип вложения и ссылку вида `https://t.me/channel/post?comment=message_id`.

Повторный выбор использует ту же загруженную ветку. Результат может повториться. Новые комментарии попадут в выборку после перезапуска приложения или загрузки другого поста и возврата к первоначальному.

Поддерживаются HTTPS-ссылки на посты публичных каналов. Telegram-аккаунту должно быть доступно обсуждение. Удалённые и недоступные сообщения в выборку не попадают.

Исходники позволяют проверить алгоритм. Организатор может запускать выбор повторно. Каждый запуск независим, публичный неизменяемый журнал результатов отсутствует.
